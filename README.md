## ELIXIR Lesson Template - Quarto

This is a beta version of the ELIXIR Lesson Template in Quarto. If you are looking for the more mature lesson template in Mkdocs, please have a look [here](https://github.com/elixir-europe-training/ELIXIR-TrP-LessonTemplate-MkDocs).

The site renderer for this template is [Quarto](https://quarto.org). Which has a lot of functionality, including code executing for Python, R and Julia. Check out the [Quarto documentation](https://quarto.org/docs/guide/) for all possibilities.
